# Vijay's Sound Bytes

A personal blog for Vijay Mathely, built as a small static website with no build step or JavaScript dependencies.

## Preview locally

Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Create a GitHub repository named `vijay-sound-bytes`, push these files to its `main` branch, then choose **Settings → Pages → Deploy from a branch → main / (root)**. GitHub Pages will serve `index.html` at the repository's Pages URL.

The included note text and dates are starter copy. Replace them with your own writing before publishing; update the title, description, and About section in `index.html` as your blog takes shape.
